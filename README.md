# Adult Census Income Classification

A data analysis project on the Adult Census dataset focusing on income classification based on demographic attributes. This project includes data cleaning, exploratory data analysis, and machine learning models to predict whether an individual's income exceeds $50K annually.

## Features

- Data preprocessing and cleaning.
- Exploratory Data Analysis (EDA) with visualizations.
- Implementation of machine learning models for classification.
- Model evaluation and performance metrics.

## Technologies Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
